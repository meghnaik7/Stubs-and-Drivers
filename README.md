# Stubs and Drivers in Integration Testing

A presentation and demonstration project explaining **Stubs and Drivers** used in **Integration Testing**.

## 📌 About the Project

This project was created as part of an academic presentation to understand how **Stubs** and **Drivers** are used when some modules of a software system are not yet available during integration testing.

The repository contains:

* 📊 Presentation on Stubs and Drivers
* 💻 Stub demonstration program
* 💻 Driver demonstration program


---

## 🧪 Demonstration

This repository contains simple programs demonstrating:

### Stub Demo

Shows how a Stub can temporarily replace a lower-level module and return predefined data.

### Driver Demo

Shows how a Driver can call and provide input to a lower-level module during testing.

## 📊 Integration Testing

Integration testing verifies that different software modules work correctly together.

When some modules are unavailable, **Stubs and Drivers** can be used as temporary replacements.

```text
              Integration Testing
                       │
             ┌─────────┴─────────┐
             ↓                   ↓
           Stubs              Drivers
             ↓                   ↓
        Top-Down             Bottom-Up
```
